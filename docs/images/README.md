# Documentation Images

This folder contains images used in the documentation.

## Required Images

- `architecture-overview.png` - High-level system architecture diagram
- `data-flow.png` - Data pipeline visualization
- `retrieval-flow.png` - Query processing flow

## Creating Diagrams

You can create these diagrams using:
- [draw.io](https://draw.io) - Free diagramming tool
- [Excalidraw](https://excalidraw.com) - Hand-drawn style diagrams
- [Mermaid](https://mermaid.js.org) - Code-based diagrams

## Recommended Image Specifications

- Format: PNG or SVG
- Width: 800-1200px
- Background: Transparent or white
- Style: Clean, professional
