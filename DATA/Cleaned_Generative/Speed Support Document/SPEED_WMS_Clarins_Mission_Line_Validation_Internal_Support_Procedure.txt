Clarins Mission Line Validation – Internal Support Procedure
Sensitivity: Internal
Audience: Support / Technical Team
System: Speed WMS
Purpose
This procedure is used to correct and validate mission lines for Clarins orders when:
• Orders are not validating correctly
• Mission lines are stuck below validation status
• Mission lines are not linked to valid stock locations
Validation must be performed only using active picking locations and open-box
stock, not reserve or full-carton stock.
Key Parameters
Before running the script, define the following:
DECLARE @ArtCode varchar(50) = '80110136'; -- SKU / Article Code
DECLARE @Stk_Keyu int = 218923; -- Selected Stock Key

• Orders with mission lines already in status 040

• Mission lines below validation status for the specified SKU

• Are in Inspection (INS) status
• Are located in picking zones
• Are actively being consumed (open boxes)

Step 3: Reassign Mission Lines to Valid Stock Location
This step updates mission lines that:
• Are in status 020
• Are not currently linked to valid stock
• Match the specified SKU
Sensitivity: Internal

[PAGE 5]
Only up to 150 mission lines are updated at a time.
BEGIN TRAN
UPDATE MIL_DAT
SET MIL_EMP = s.STK_LIEU
FROM (
SELECT STK_LIEU, STK_NoSU, STK_LOT1, STK_DLUO
FROM STK_DAT
WHERE STK_KEYU = @Stk_Keyu
AND ART_CODE = @ArtCode
) s
WHERE MIL_STAT < '040'
AND MIL_KEYU IN (
SELECT TOP 150 M.MIL_KEYU
FROM MIL_DAT M
LEFT JOIN STK_DAT S
ON M.ACT_CODE = S.ACT_CODE
AND M.ART_CODE = S.ART_CODE
AND M.MIL_EMP = S.STK_LIEU
AND M.MIL_NoSU = S.STK_NoSU
WHERE M.ACT_CODE = 'RSAJHBCLA'
AND M.MIL_STAT = '020'
AND S.STK_KEYU IS NULL
AND M.ART_CODE = @ArtCode
)
COMMIT TRAN

Critical Business Rules (Must Be Followed)
Stock Selection Rules
• Only Active Picking Locations
• Do NOT use Reserve Locations
• Do NOT use Full Cartons
• Only Open-Box Stock
How to Identify Open-Box Stock
• If multiple LPNs for the same SKU have identical quantities, these represent full
cartons → Do not use
• If an LPN shows quantity being reduced, it represents an open box → Valid for
validation
Important Notes
• Validation from reserve stock must be handled via the replenishment process
• This script is intended for Support use only
• Always verify stock behavior before assigning STK_KEYU
