19. Item Code Updates
View Item
SELECT *
FROM ART_PAR
WHERE ACT_CODE = 'Activity Code'
AND ART_CCLI = 'Customer Account';
Update Item
UPDATE ART_PAR
WHERE ACT_CODE = 'Activity Code'
AND ART_CCLI = 'Customer Account'
AND ART_KEYU = 'Item KEYU';
Important:
If stock already exists, you must also update:
• Movements
• Stock
• Reception Lines

23. Orders – Reversal from Shipped (070)
Revert Order to Packed
SELECT *
FROM OPE_DAT
WHERE ACT_CODE = 'Activity Code'
AND OPE_NOOE = 'Order Number';
UPDATE OPE_DAT
SET OPE_STAT = '060'
WHERE ACT_CODE = 'Activity Code'
AND OPE_NOOE = 'Order Number';
Important Process Notes
• After reverting to Packed (060):
o Continue actions in Speed, not SQL
o Move order back to Validated
o Then to Preparation
o Then to Seizure (010)
Only at Seizure can the order be modified or deleted.
