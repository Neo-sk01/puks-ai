• 4. Context
Within the scope of the L'ORÉAL activity, we use the multi-BL reception module for receiving various
items.
However, it sometimes happens that certain information, such as dimensions (length, width, height) or
weight, are not entered in the item master.
The client wishes that if at least one of the three dimensions is not entered, the operator should be
required to complete them directly from the multi-BL reception module. The same applies to weight.
Furthermore, for certain items, during their first reception, we do not know if they are subject to lot 1
management or expiration date (DLC) management.
The client also wishes to be able to enter case and pallet handling units. If the value is > 0, then we will
additionally activate management of this handling unit.
The client also wishes to implement an option in the multi-BL reception module that will allow, during
this first reception, to define whether the item is concerned by lot 1 management and/or by DLC.

this, we will use ACT_TOP16.

• 6. Technical Section
In PE 602 and PE 794, control that ACT_TOP16=1 before performing processing. No activity-level control
to perform.
First, if we are on the first reception of the item, across all receptions in the activity, display the possibility
to manage or not lot 1 and DLC, and also the possibility to enter quantity per case and per pallet.
Then we will verify if dimensions are properly entered for the item per unit. We must ensure that
ART_LONU, ART_LARU, and ART_HAUU are properly entered and greater than 0.

• 6.1 PE794
If first reception of item:
→ Display possibility to activate item for lot1 and DLC
→ Entry of quantity per case/pallet:
• If case quantity > 0, then we consider that we manage cases. The quantity entered will be in
units per case.
• If pallet quantity > 0 and case quantity > 0, then quantity entered is in cases per pallet.
• If pallet quantity > 0 and case = 0, then quantity entered is in units per pallet.
Remember to update the unit if it's in cases or units as below: from the moment quantity equals 0, we
will always have unit by default. If VL case > 0, then at pallet level we will have number of cases.
→ If first-time reception of item, update ART_LOT1 and ART_DLC (if activated, set to 1, otherwise set to
0)
Remember to update ART_PREP if ART_LOT1 managed and ART_DLC managed as below:
→ If ART_LOT1 managed and if ART_DLC managed then: If an item manages lot, we must consider that
it manages optimal use-by date as well as manufacturing date.
• ART_PREP1 = STK_DLC & ART_DDLC=1
• ART_PREP2 = STK_DLUO & ART_DLUO=1
• ART_PREP3 = STK_DAEN
• ART_PREP4 = STK_LOT1 & ART_LOT1=1
• ART_PREP5 = STK_DFAB & ART_DFAB=1
→ If ART_LOT1 NOT managed and if ART_DLC managed then:
• ART_PREP1 = STK_DLC & ART_DDLC=1
• ART_PREP2 = STK_DAEN
→ If ART_LOT1 managed and if ART_DLC NOT managed then:
• ART_PREP1 = STK_DLUO & ART_DLUO=1
• ART_PREP2 = STK_DAEN
• ART_PREP3 = STK_LOT1 & ART_LOT1=1
• ART_PREP4 = STK_DFAB & ART_DFAB=1
In Speed, we cannot manage traceability without it being entered in ART_PREP.
Remember to update ART_PREP entered with STK_LOT1 and STK_DLC in case of non-management of
these options.
