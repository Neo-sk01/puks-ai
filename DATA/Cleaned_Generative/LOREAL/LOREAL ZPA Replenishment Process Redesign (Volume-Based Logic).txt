SECTION 1 — Business Context
1.1 Background
As part of the L’Oréal project, the ZPA replenishment process is being redesigned
to:
• Improve handling of partial replenishments
• Consider real volume constraints of storage locations
• Optimize flow between pallets/boxes and dynamic picking locations
Sensitivity: Internal

[PAGE 2]
1.2 Current Limitations
The existing ZPA process:
• Transfers full supports only
• Does not calculate actual available volume
• Does not split intelligently based on capacity
This causes:
• Lack of shelf space
• Large variability in article volume (lipsticks vs bottles)
• No automatic calculation of remaining capacity
• Manual management of partial replenishments
SECTION 2 — Functional Objectives
The workshop defined the following goals:
1. Automatically split replenishments according to destination volume.
2. Fill picking locations based on volume, not only quantity.
3. Improve ergonomics in the replenishment module.
4. Make ZPA replenishment more dynamic (triggered at wave launch).
5. Manage saturated locations (rejection or deferred handling).
6. Handle residual quantities via rejection location.
7. Avoid intrusive changes in standard launch module.

Location Eligibility Criteria
For the new stock line, search empty eligible locations based on:
• Destination Zone

Threshold Rule
If threshold reached (ART_NUM2):
NO available location returned
Volume Check
Before assigning location:
required_volume = article_volume × quantity_to_store
Article volume must be taken from:
art_dim table – unit dimensions (500)
If required volume fits → assign location.

SECTION 4 — ZPA Residual (Rejection) Management
If stock cannot be stored:
→ Automatically sent to a destination location of type:
REJET (Rejection)
Behavior Rules
• Stock lines without valid location remain in status 03.
• They are NOT converted into replenishment mission lines.
Entry Point Modification
PE482 (end of ZPA process) must be modified:
Sensitivity: Internal

[PAGE 5]
GENERATE replenishment missions
ONLY IF destination_location_type ≠ REJET
REJET Lines
Lines linked to REJET location:
• Remain in status 03
• No mission generation
Contextual Menu
A specific contextual menu will allow operators to:
Change status from 03 → 01
Clear STK_LIEUP
Relaunch ZPA using standard process
