SECTION 2 — Inventory Creation & Index Management
2.1 Standard Inventory Creation
• Type: Inventaire général
• Inventory code: max 11 characters
• Automatic counter for indices (last 4 chars, separated by _)
• Index displayed in a dedicated IHM field
Example:
Displayed code: 20250211
IVE_DAT.IVE_CODE: 20250211_001
IVE_ALPHA1: 20250211
2.2 Business Rules
RG Code Description
Inventory code ≤ 11 chars; special chars allowed except _; code
SPD023_CDI_RG_001
= input + _ + index
Index init = 001 in new mode; decode code if existing; display in
SPD023_CDI_RG_002
dedicated field
SPD023_CDI_RG_003 IVE_CODE = input + _ + index; IVE_ALPHA1 = input

SECTION 4 — Discrepancy Management
4.1 Standard Cases
• Case 1: No discrepancies → inventory validated & closed
• Case 2: Discrepancies but no new count → validate or delete discrepancies →
close inventory
4.2 Specific Case
• Case 3: Discrepancies require new count
• New partial inventory created, linked via automated index
• Inventory lines without discrepancy automatically validated
• Full location recomputation (not only items with discrepancy)
• Repeatable up to 999 recounts
Example:
General inventory: 20250211_001
Partial inventory: 20250211_002
IVE_ALPHA1 = 20250211
SECTION 5 — PE171: Generate Discrepancies
• PE171 used for discrepancy processing
Sensitivity: Internal

[PAGE 4]
• Wrapped in F_Transaction for DB atomicity
• Business Rules:
o SPD023_GLE_RG_001 → check lines with discrepancies
o SPD023_GLE_RG_002 → close current index, update stock, free locations,
set IVE_STAT = '050'
o SPD023_GLE_RG_003 → create new index, duplicate lines in discrepancy,
reset quantities
• Controls & Actions:
o SPD023_GLE_CTRL_001 → lines with discrepancies exist?
o SPD023_GLE_CTRL_003 → inventory header exists?
o SPD023_GLE_CTRL_004 → inventory status correct?
o SPD023_GLE_ACT_001 → confirmation dialog for new count or close
SECTION 6 — PE261: Traceability Windows
• Fen_IV01200_SPE → duplicate standard Fen_IV01200 for multiple-count
traceability

IVL_TCPT=1, IVL_QUGC=0, STK_QTE=0, IVL_TOIN=null
