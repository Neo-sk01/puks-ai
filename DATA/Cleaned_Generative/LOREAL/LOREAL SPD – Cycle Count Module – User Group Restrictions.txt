4.1 Functional Context
Within the L’ORÉAL activity, the standard Cycle Count module is used.
This module:
• Does NOT rely on a dedicated inventory zone.
• Does NOT block warehouse locations.
• Allows immediate stock updates based on declared quantities.
The radio cycle count module is used for stock adjustments, especially when:
• A pallet is found in the warehouse without an assigned location.
• A stock support needs to be consumed or modified.
4.2 Business Requirement
Since this module is accessible to all radio operators, the client requires restriction of
certain options depending on the user profile.
Access to specific functionalities must be controlled based on:
The user group of the connected operator.

5.2 User Group Configuration
Parameter Description
ACT_ALPHA12 List of restricted user groups separated by ";"
Example:
USER;TEMP;EXTERNAL
If the logged-in user belongs to one of these groups:
→ Restricted options must be hidden.

Condition
IF ACT_TOP22 = 1
Then:
1. Retrieve logged-in user's group
2. Check if user group exists in ACT_ALPHA12
3. If YES:
o Hide restricted options

o Display full standard option list
