Global Changes – Overview
The Global Changes function allows you to modify certain characteristics of
multiple orders at once rather than individually.
Access
• Where: Contextual menu in the orders portfolio.
• When: After selecting one or more orders in entry (In seizure).
Modifiable Fields Globally
You can change the following attributes for all selected orders:

Purpose
• Streamlines order management.
• Saves time by avoiding repetitive modifications on multiple orders.
• Ensures consistency in preparation and shipping parameters across
selected orders.
