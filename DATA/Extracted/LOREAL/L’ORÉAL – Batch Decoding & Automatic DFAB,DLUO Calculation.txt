2. Business Context
Within the L’ORÉAL activity, the Multi-BL Reception module is used to receive
articles.
A control must be implemented to:
Decode the received batch number (LOT)
Automatically determine:
• Manufacturing Date (DFAB)
• Best Before Date (DLUO)
⚠ The decoding logic depends on how the batch number is entered:
• Manually entered
• Retrieved from standard EAN128 scan
3. Functional Design
3.1 Activation Parameter
Control is applied only if:
Sensitivity: Internal

[PAGE 2]
ACT_TOP18 = 1
If ACT_TOP18 ≠ 1:
→ No automatic decoding is performed.
4. Batch Decoding Rules
There are two distinct decoding methods:
4.1 Method 1 – "Before ISIS"
Condition
The batch number:
• Starts with "+"
• Has the same length as ACT_ALPHA1
• Mask defined in activity IC:
ACT_ALPHA1 = "+AJJJX"
4.1.1 Mask Interpretation
The mask is dynamic.
We must retrieve:
• Position of first "A" (Year)
• Number of consecutive "A"
• Position of "JJJ" (Day of year)
⚠ Positions are NOT fixed — must be dynamically extracted from ACT_ALPHA1.
Year (A)
• Extract position of "A"
• Use transcoding table where:
TRANS_NAME = "AYR"
Example:
Sensitivity: Internal

[PAGE 3]
K → 2013
Day of Year (JJJ)
• Extract numeric day (001–365 or 366)
• Must respect leap year logic
Examples:
001 → 01/01
365 → 31/12 (non-leap year)
366 → 31/12 (leap year)
Example – Case 1
Batch:
+K0060
Article:
ART_NUM1 = 10
From TRANS table:
K → 2013
006 → 6th day of year
DFAB:
06 January 2013
DLUO:
DFAB + ART_NUM1 days
06/01/2013 + 10 = 16/01/2013
4.2 Method 2 – "After ISIS"
Condition
The batch:
• Does NOT start with "+"
Sensitivity: Internal

[PAGE 4]
• Contains at least one letter
• Has same length as ACT_ALPHA2
• Mask defined in:
ACT_ALPHA2 = XXAMXX
4.2.1 Mask Interpretation
Positions must be dynamically extracted.
Retrieve:
• Position of "A" → Year
• Position of "M" → Month
Year (A)
Use transcoding table:
TRANS_NAME = "BYR"
Example:
J → 2012
Month (M)
Use transcoding table:
TRANS_NAME = "AMO"
Example:
7 → July
O → October
N → November
D → December
Default rule:
Manufacturing date = First day of extracted month
Sensitivity: Internal

[PAGE 5]
Example – Case 2
Batch:
2YJ700
Article:
ART_NUM1 = 10
From TRANS table:
J → 2012
7 → July
DFAB:
01 July 2012
DLUO:
01/07/2012 + 10 days = 11/07/2012
4.3 Invalid Batch
If the batch:
• Does not start with "+"
• Does not match ACT_ALPHA2 format
• Does not contain required letter positions
→ It cannot be decoded.
In this case:
• DFAB must be manually entered
• DLUO must be manually entered
• DLC remains manually entered (no relation to batch)
5. DLUO Calculation Rule
Once DFAB is determined:
DLUO = DFAB + ART_NUM1 (Number of days between DFAB and DLUO)

7.1 PE882 – Reception
• Duplicate standard window into specific version
• Perform decoding logic inside specific window
• DLC remains manual
Check:
ACT_TOP18 = 1
Then:
Logic Summary
IF LOT starts with "+" AND matches ACT_ALPHA1 length:

→ Decode using AYR
→ Extract JJJ
→ Calculate DFAB
→ Calculate DLUO

B → 2005
...
