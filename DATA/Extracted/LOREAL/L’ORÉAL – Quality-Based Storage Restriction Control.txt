• 2. Business Context
As part of the L’ORÉAL warehouse operations, the Multi-BL Reception module is used for receiving
articles.
The reception process is configured to operate in Declarative Storage mode.
Additionally, operators may perform storage using:
• The Standard Radio Storage module (Cariste module)
• 2.1 Business Requirement
The client requires:
To prevent certain quality-coded items from being stored in specific zones.
This restriction must depend on:
• The quality code of the item
• The zone configuration
• 3. Functional Design
• 3.1 Zone Configuration Logic
The restriction mechanism uses:
• Zone IC (Information Code): ZEM_ALPHA1
• Maximum length: 50 characters
• Quality codes must be separated by: ;
• Example:

If ZEM_ALPHA1 is empty:
→ No storage restriction applies.
• 3.2 Important Technical Constraint
Speed WMS does NOT support variable IC at zone level.
Therefore:
• ZEM_ALPHA1 must be used
• Limited to 50 characters
• 3.3 Activation Parameter
Control must only apply if:
• ACT_TOP17 = 1
If ACT_TOP17 ≠ 1:
→ No control is performed.
This control does NOT apply in Speed Admin.
It only applies from the Radio interface.

• 4.3 Validation Logic (PE863)
Condition: ACT_TOP17 = 1
• Case 1 – Location belongs ONLY to zones that forbid the quality
If the flashed location belongs exclusively to zones where:
• Current Quality Code ∈ ZEM_ALPHA1
Then:
• Display error message:
English:
• Zone XXX is not authorized for storage of items with quality code YYYY
• Clear the location input field
• Block validation
• Case 2 – Location belongs to multiple zones
If:
• At least one zone allows the quality
• And another zone forbids it
Then:
→ Storage must be ALLOWED
(Standard behavior continues)

• 5.3 Validation Logic (PE222)
Condition: ACT_TOP17 = 1
• Case 1 – All associated zones forbid the quality
If the flashed location belongs only to zones where:
• Current Quality Code ∈ ZEM_ALPHA1
Then:
• Display error message:
• Zone XXX is not authorized for storage of items with quality code YYYY
• Return FALSE
• Block storage
• Case 2 – At least one zone allows the quality
If:
• Location belongs to multiple zones
• At least one zone allows the quality
Then:
• Return TRUE
• Allow storage

• PE863 Processing Logic
If ACT_TOP17 = 1:
• IF location belongs ONLY to zones that forbid quality:
• → Show error
• → Clear input field
• → Block validation
•
• IF location belongs to multiple zones AND at least one allows quality:
• → Do nothing
• → Continue standard storage
• 6.2 PE222 – Cariste Storage
If ACT_TOP17 = 1:
• IF location belongs ONLY to zones that forbid quality:
• → Show error
• → Return FALSE
•
• IF location belongs to multiple zones AND at least one allows quality:
• → Return TRUE
