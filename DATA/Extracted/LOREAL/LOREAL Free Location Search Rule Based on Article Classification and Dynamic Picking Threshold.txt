SECTION 1 — Business Context
1.1 Functional Context
Within the L’Oréal project, several location search rules are defined to meet
storage constraints.
These rules are based on article classification criteria.
The client now wants to configure a Free Location Search rule that:
• Counts the number of locations containing a specific article within a defined
zone.
Sensitivity: Internal

[PAGE 2]
• Applies decision logic based on:
o Article Division (ART_ALPHA11 – Level 2 classification)
o Aerosol level (ART_ALPHA3)
o Dynamic picking threshold (ART_ALPHA10 – ART_NUM2)
1.2 Objective of the Rule
The rule must:
1. Count the number of locations containing the same article within a given
zone.
2. Compare that count to the article’s dynamic picking threshold
(ART_ALPHA10).
3. Apply the following logic:
Case 1 — Location Count < Threshold
→ Assign a new free location in the defined zone.
Case 2 — Location Count ≥ Threshold
→ Do not propose a new location.
→ Move to the next storage sequence (e.g., reserve storage).

SECTION 5 — Core Logic
Threshold Control
location_count = COUNT_LOCATIONS(article, zone)
threshold = ARTICLE.ART_NUM2
IF location_count >= threshold THEN
RETURN NO_LOCATION
ELSE
RETURN FREE_LOCATION_IN_ZONE
ENDIF
Behavior
• If threshold reached → do not propose location
• If threshold not reached → propose free location in defined zone
