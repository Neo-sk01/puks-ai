SECTION 1 — Business Context
1.1 Functional Context
Within the L’ORÉAL activity, the standard Cycle Counting module is used.
This module:
• Does not rely on a specific inventory zone.
• Does not block storage locations.
• Allows immediate stock updates based on declared quantities.
The radio cycle counting module is used by warehouse teams for stock adjustment,
particularly in the following situations:
• When a pallet is found in the warehouse without an assigned location.
Sensitivity: Internal

[PAGE 2]
• When consuming or modifying a stock support.
1.2 Business Requirement
Since this module is accessible to all radio operators, the client wants to restrict
access to certain options based on the user profile.
Access to specific functionalities must depend on the user group.
1.3 User Group Restriction
Initially:
The USER group will NOT have access to the following options:
• Modify Quality
• Modify Traceability Elements
• Modify Packaging
• Reset (to be confirmed with client)
• New Reference
The list of user groups concerned will be configured in:
ACT_ALPHA12
Group names must be separated by a semicolon (“;”).
1.4 Standard Options Available in the Module
The standard module includes the following options:
• Modify Quality
• Modify Traceability Elements
• Modify Template
• Modify Packaging
• Reset
• Support Label
• New Reference
Sensitivity: Internal

[PAGE 3]
• Modify Movement Reason
• Unit Control
• Declare Event
• Modify Variable Information
1.5 Activation Parameter
A specific activity parameter will control whether the restriction logic is applied.
Parameter:
ACT_TOP22
If:
ACT_TOP22 = 1
→ Restriction logic is activated.
If:
ACT_TOP22 = 0
→ Standard behavior (no restriction).

SECTION 3 — Technical Implementation
3.1 Entry Point Used
Entry Point Description
PE 884 Option window initialization logic
3.2 Technical Condition
When:
ACT_TOP22 = 1
Then:
Use PE 884 to filter visible options.
3.3 Filtering Logic
If the connected user belongs to the group configured in:
ACT_ALPHA12
Then the following options must be hidden:
Sensitivity: Internal

[PAGE 5]
• Modify Quality
• Modify Traceability Elements
• Modify Packaging
• Reset
• New Reference
3.4 Logical Flow (Pseudo-Code)
IF ACT_TOP22 = 1 THEN
restricted_groups = GET_VALUE(ACT_ALPHA12)
IF current_user.group IN restricted_groups THEN
HIDE_OPTION("Modify Quality")
HIDE_OPTION("Modify Traceability Elements")
HIDE_OPTION("Modify Packaging")
HIDE_OPTION("Reset")
HIDE_OPTION("New Reference")
ENDIF
ENDIF
