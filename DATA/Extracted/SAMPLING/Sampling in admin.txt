Topic: Automated Sampling During Receiving
Trigger: Sampling is automatically executed whenever stock is generated in
SpeedWMS, either through:
• The Administrative (backend) interface, or
• Radio Frequency (RF) transactions using reception modules (Standard
Reception, Multi-BL Reception).
Prerequisite: Sampling rules must be configured and active for the received items.
1. Process Overview & Example
When a receiving order matches an active sampling rule, the system automatically
creates a sample.
• Example Scenario:
o Items Received: G50OXF90 and G50OXFA3
o Applied Rule: For items in the "Standard paper" item family.
o Rule Action: Take 2 units, place them in location W01-B-01-0-1, and
assign the quality code CTRL.
2. Viewing Sampling Results
The results of automated sampling can be viewed at three levels in the system:
A. Storage Tab (of the Completed Receipt)
• Visual Impact: The original receipt lines appear "burst" or split. In the
example, four lines display instead of two.
• Sample Details: The sampled units are shown on a new, auto-incremented
support (handling unit).
• Status: They are located in the predefined sampling location with the CTRL
quality code.
• Special Case for Serial Numbers: If the item manages serial numbers, a
dedicated screen prompts the user to select the specific serial numbers for
the new sample support during the burst process.
B. Stock Movements
Three distinct stock movements are logged for each sampled item:
1. Receiving Input: The initial input of the full received quantity.

2. Sampling Output: An output representing the quantity removed from the
original support for sampling (causing the support split).
3. Sampling Input: An input representing the creation of the new support
containing the sample quantity.
C. Events
The system logs events related to all receiving activities and the associated stock
inputs and outputs generated by the sampling process.
3. Important Configuration Note for RF Receiving
When receiving goods via SpeedRadio (RF):
• Operators must verify that "Stock generation" is enabled in the settings of
the specific reception module being used.
• All sampling-related settings must also be checked and correctly configured
for the automated process to function as intended.
