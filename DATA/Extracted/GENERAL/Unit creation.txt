Unit Creation – RAG-Friendly Version
Purpose:
Define and create new warehouse locations in SpeedWMS with all relevant
characteristics to optimize storage, picking, and logistics operations.
1. Mandatory Location Elements
When creating a location, the following characteristics must be defined:
Field Description Type / Max Length
Warehouse Warehouse code Alphanumeric, 6 chars max
Aisle Aisle identifier Alphanumeric, 3 chars max
Column Column identifier Alphanumeric, 3 chars max
Level Level identifier Alphanumeric, 3 chars max
Slot Slot identifier Alphanumeric, 3 chars max
Note: Warehouse and Slot are mandatory. The final location name is automatically
generated by concatenating all 5 characteristics but can be manually edited
(Alphanumeric, 25 chars max).

3. Summary
• All mandatory fields must be completed to create a location.
• Optional fields improve storage optimization, picking accuracy, and stock
safety (weight, multi-reference, dimensions).
• Templates and classes support automated location searches.
• Walkable and weight management settings enforce operational compliance
during RF scanning and stock movements.
