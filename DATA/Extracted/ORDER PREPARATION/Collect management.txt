Collect Management Overview
Purpose:
• Optimize the movements of preparers in the warehouse.
• Group samples from multiple orders/missions to pick all required quantities
in one trip per location.
• Important: The collect process does not validate mission lines. Stock
decrement happens during distribution or packing.
Access:
Preparation / Manage collect mission
Collect Screen Overview
• The window displays all collects, divided by status:
Tab Description
Generated Collects created but not yet started. Default tab on opening.
In Progress Collects that are currently being executed.
Closed Completed collects.
All Displays all collects regardless of status.

Collect Notes
• For each collect, a collect note can be printed via the Print button on the
order bar.
• Provides a summary of the items and quantities to be picked for that collect.
Processing
• Normally handled via the SpeedRadio module (RF devices).
• Can also be executed administratively if needed.
Key Notes
• Collects group multiple orders/missions but do not finalize stock
allocations.
• Only Generated collects (010) can be edited or deleted.
• Supports user assignment, organization, and reporting.
Sensitivity: Internal
