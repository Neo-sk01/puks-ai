Creating and Modifying an Order
Access
• Manual creation: Click the New button in the control bar.
• Interface creation: Orders can also be created automatically via external
interfaces.
Modifying Orders
• Orders can be modified only if their status is “In Seizure” (010).
• For orders in advanced statuses, the status must first be reverted to In
Seizure using the available operations.
• Double-clicking on an order opens the modification screen.
Order Structure
Orders are made of Header data and Order line data:
• Order Header: Contains general information about the order.
• Order Lines: Cannot exist without a header; list of items and quantities for
the order.

Order Lines
• The first line is a simplified entry line for items/quantities.
• The bottom table lists all goods in the order, showing what must be taken
from stock.
• Adding lines: Multiple methods available (manual, templates, or import).
