1. Reversal of a Closed GRN
this step can only bae done by the support teams as they have access to the
database.
Check the GRN status:
SELECT REE_ETRE, REE_KEYU, REE_CCLI, *
FROM REE_DAT
WHERE ACT_CODE = ' Activity Code’
AND REE_NORE = ‘Receipt Number ‘;
Sensitivity: Internal

[PAGE 2]
Notes:
• ACT_CODE = Activity Code
• REE_NORE = Receipt Number
• REE_ETRE = GRN Status
• REE_KEYU = Receipt ID
Sensitivity: Internal
• REE_CCLI = Customer Account Code
• REE_TOP1 = Status for Pegasus: 1 = sent, 0 = not sent
Optional update to reverse a closed GRN:
UPDATE REE_DAT
SET REE_ETRE = '100',
REE_TOP1 = 0
WHERE ACT_CODE = ' Activity Code’
AND REE_NORE = ‘Receipt Number ‘;
AND REE_KEYU = ' Receipt ID '
AND REE_CCLI = ' Customer Account Code ';
2. Checking Receipt Lines
Query all lines for a given receipt:
SELECT REE_KEYU, REL_KEYU, REL_NoSU, *
FROM REL_DAT

3. Resending Files to Pegasus
Reset the REE_TOP1 flag for resending:
UPDATE REE_DAT
SET REE_TOP1 = 0
WHERE ACT_CODE = ‘Activity Code'
AND REE_NORE = ' Receipt Number'
AND REE_KEYU = ' Receipt ID'
AND REE_CCLI = ‘Customer Account Code’;
Sensitivity: Internal
