Import thirds
Available via Settings / Thirds.
A click on the Import button then on Browse allows to select the file to import.
The process remains the same whether importing suppliers, carriers or consignees.
Speed identifies these three types of third parties using the following coding:
.001 corresponds to a supplier
.002 corresponds to a carrier
.003 corresponds to a recipient
It is possible to import the three types of third parties in the same file. A column named
Type of Third must therefore systematically be added to the import file.
